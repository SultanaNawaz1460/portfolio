Multi-agent deep reinforcement learning

Intelligent conflict resolution in 5G NR network slicing

Network slices compete for the same radio resources, and the moment traffic gets uneven they start stepping on each other. I built a full 5G NR environment to reproduce that conflict, then trained cooperating agents to allocate resources around it.

  • Simulated a complete 5G NR environment with realistic traffic patterns and heterogeneous slices
  • Trained a multi-agent DRL policy for dynamic, conflict-aware resource allocation
  • Benchmarked against a baseline allocator rather than reporting reward in isolation
